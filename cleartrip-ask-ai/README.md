# Cleartrip Ask AI

Interactive Razorpay × NID design assignment prototype for the Weekend Escaper.

Open `index.html` in a browser. The prototype uses plain HTML, CSS and JavaScript with local image assets. AI responses, dates, prices, availability and booking actions are simulated.

Start at the Cleartrip home screen or expand **Try a scenario** to jump to any branch. For the main demo, use the ₹15K request, explore Bhandardara, inspect a stay, choose food and transport, and approve the plan in the booking review. Choose **Car** and **Cottage** to see the budget trade-off.
